NAT 게이트웨이 목록 및 생성

Network > NAT Gateway 화면의 구성 요소와 동작 규칙을 정의한다. 기존 화면(v2)을 실제 브라우저에서 실행해 화면·DOM·스타일을 함께 추출하고, 소스 코드로 규칙을 확인해 작성했다.

읽는 법 — 화면 안의 번호는 아래 정의 표의 No.와 1:1로 대응한다. 정의 표의 정책 · 유효성은 실제 화면에서 관찰했거나 소스 코드로 확인한 내용만 적었다. 확인 필요로 표시한 항목은 근거가 한쪽뿐이라 리뷰에서 판단이 필요하다.

무엇이 어디에 있나

화면은 사용자가 하는 일(조회 · 생성 · 수정 · 삭제) 순서로 놓았다.

  1. 전체콘솔 창 전체 모습 — 화면이 원래 어디에 있나
  2. F-01목록 조회 — 검색·버튼·컬럼 17개
  3. F-02생성 — 입력 항목 10개
  4. F-02-1생성 중 플로팅 IP 발급 — IP 풀이 둘 이상일 때만
  5. F-02-2드롭다운 펼친 모습 — 단일 선택, 잠긴 항목
  6. F-03수정 — 이름·설명만 고칠 수 있다
  7. F-04삭제 확인 — 되돌릴 수 없다
  8. F-05하단 상세 조회 — 탭 2개
  9. RULE권한에 따른 화면 차이 — 요구 권한과 판정 순서
  10. FLOW사용자 액션별 유저 플로우 — 흐름도 6장, 필요한 기능, 용어
  11. 고칠 점개편 시 반영이 필요한 항목 — 확정 3건, 미결 4건

상품ID는 프로젝트의 상품ID를 쓴다. 역할 이름은 {상품ID}_{권한명} 형태로 조립해 사용자가 가진 역할 목록과 대조한다.

리뷰에서 결정이 필요한 항목

관찰한 사실이지만 결론이 난 정책이 없다. 개편에 넣을지 리뷰에서 정한다.

여기 있는 항목은 이렇게 갱신한다 — 결정이 나면 이 문서를 고쳐 해당 항목을 확정으로 옮기고 근거가 된 업무를 링크로 건다. 문서 버전을 올려 저장소(docs/deliverable/)에 커밋한다. 무엇이 왜 바뀌었는지는 커밋과 해당 업무 댓글에 남는다. 문서만 고치고 근거를 남기지 않는 일은 하지 않는다.
